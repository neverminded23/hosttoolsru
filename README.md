# HostTools (Purpur / Paper / Spigot 1.21.x)

Команды хоста только для операторов. Все команды начинаются с `h`, чтобы не конфликтовать с ванильными.
Права: `hosttools.use` (все команды, по умолчанию **op**) и `hosttools.bypass` (иммунитет к муту чата / слоумоду / заморозке всех / очистке чата, по умолчанию **op**).

Список команд в игре: `/hhelp`.

## Сборка
Нужны JDK 21 и Maven:  `mvn package`  -> `target/HostTools-1.0.0.jar`  -> положите в папку `plugins/` сервера и перезапустите его.

Нет инструментов? Залейте эту папку в репозиторий GitHub: готовый workflow (`.github/workflows/build.yml`) соберёт jar сам (Actions -> build -> Artifacts).

## Команды
| Команда | Что делает |
|---|---|
| `/hshout <сообщение>` | громкое объявление в чат для всех + звук |
| `/hscreen <заголовок> [\| подзаголовок]` | крупный текст по центру экрана + звук |
| `/hall <сообщение>` | объявление в чат И текст на экран |
| `/hbar <сообщение>` | текст в экшен-баре на 5 сек + звук |
| `/hmute <игрок\|all> [причина]` / `/hunmute <игрок\|all>` | мут игрока (работает и для оффлайн) / всего чата |
| `/hmutelist` | кто в муте, состояние мута чата и слоумода |
| `/hwarn <игрок> <причина>` | предупреждение на экране + в чате + звук, сохраняется с датой и именем хоста |
| `/hwarns <игрок>` / `/hunwarn <игрок>` | посмотреть / снять предупреждения |
| `/hdm <игрок> <сообщение>` | личное сообщение от хоста (чат + экшен-бар + звук) |
| `/hsc <сообщение>` | чат только для операторов |
| `/hclearchat` | очистить чат для неоператоров |
| `/hslow <секунды\|off>` | слоумод |
| `/hfreeze <игрок\|all\|off>` | заморозить/разморозить (для игрока работает как переключатель) |
| `/hcountdown <секунды\|cancel> [текст в конце]` | крупный отсчёт на экране со звуками |
| `/hheal` / `/hfeed <игрок\|all>` | вылечить / накормить |
| `/hfly [игрок]` | вкл/выкл полёт |
| `/hvanish [игрок]` | скрыться от неоператоров |

Цвета: используйте `&` коды (`&c` красный, `&l` жирный ...) в сообщениях. Игрокам в муте также запрещены `/msg`, `/me`, `/say` и т. д. (список в `config.yml`). Муты и предупреждения хранятся в `plugins/HostTools/data.yml`.
